# Agenda-Abierta

## Objetivo
SaaS de agendamiento online para barberías independientes: reservas 24/7, dashboard de agenda y servicios, cobro con Stripe y recordatorios automáticos.

## Stack y arquitectura
- Frontend: React + Vite + TypeScript (`frontEnd/`)
- Backend: FastAPI (`app/`), migraciones en `migrations/`
- DB: Supabase (Postgres)
- Infra / deploy: Docker + Render (`render.yaml`); pagos con Stripe
