# irma

## Objetivo
PWA de conciencia situacional táctica tipo ATAK para uso civil (SAR, seguridad de eventos, expediciones): seguimiento de equipo en vivo, gráficos tácticos, chat y pánico sobre celular, Wi‑Fi o malla LoRa fuera de red.

## Stack y arquitectura
- Frontend: Next.js PWA, React, Leaflet (tiles CARTO) / MapLibre, Three.js, milsymbol, Zustand
- Backend: relay WebSocket (`relay/`); transporte LoRa vía Web Serial / Web Bluetooth
- DB:
- Infra / deploy: Render (`render.yaml`)
